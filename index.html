Compact 5 CAM — quick guide

  
Workflow

  
    
    
  1. Setup: stock diameter, controller type, clearances and the tool start position (where you park the tool before START).
    2. 
    
  2. Profile: draw the upper half of the part from the face (Z = 0) toward the chuck (−Z), or import a DXF. Arcs are set per segment (radius + G02/G03). Use Fillet / Chamfer on a corner point.
    3. 
    
  3. Operations: add Facing, Rough turning, Finish contour, Groove, Parting, Drilling, Thread, Tool change or Custom blocks. Order = program order.
    4. 
    
  4. Program: check the listing and warnings, scrub the simulation, then Send to the lathe or Download a .CNC file for Mike's Free Interface.
    5. 
  

  
Lathe conventions used

  
    
    
  • X values are diameters in 1/100 mm (G92 / absolute mode), Z in 1/100 mm, feed F in mm/min.
    • 
    
  • Arcs are G02 (clockwise) / G03 (counter-clockwise) viewed with Z to the right and X up, each followed by an M99 block with the positive I (radial) and K (axial) distances from the arc start to its centre. Arcs are split automatically at quadrant boundaries.
    • 
    
  • Mk1/Mk2 controllers have no M-codes: the program ends with G22, pause is G20, tool change G26. Their arcs only allow fixed radii — tick "Arcs as short lines" in the Finish operation.
    • 
    
  • Thread (G33) and tool change (M06 / G26) block layouts have not been verified against a real machine. Receive a program from your lathe that uses them and compare before relying on them.
    • 
  

  
Sending

  
Web Serial works in Chrome and Edge. Connect, pick the COM port of your cable, put the lathe in receive mode (G66 INP INP, display "A LO", START) and click Send. If blocks go missing, raise the delay per line. To check the exact format your machine expects, send a program from the lathe (G66 in output mode) and look at the received text.

  
Keys

  
S select · A add points · P pan · F fit · Del delete point · Ctrl+Z / Ctrl+Y undo / redo · mouse wheel zooms · drag empty space to pan.
